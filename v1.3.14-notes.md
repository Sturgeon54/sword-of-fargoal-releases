## What's new in v1.3.14

### Fullscreen UI auto-scaling
- Menus, overlays, and panels now scale with your display tile size — title, pause, help, settings, sprite guide, defeat/victory, and update screens
- Menu buttons, panel widths, and row heights grow on ultrawide and 4K fullscreen instead of staying at fixed pixel sizes
- Update banner buttons and restart controls scale so labels no longer clip at 3440×1440
- Title footer hotkeys wrap onto multiple lines on narrow frames instead of running off-screen

**New players:** run **Sword-of-Fargoal-Setup.exe**.

**Updates:** use **Update Now** in-game (v1.2.46+), or download **Sword-of-Fargoal.zip** and extract over your install folder.
